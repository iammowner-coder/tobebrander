# tobebrander 가격표 (초안 v1 · 2026-11-26)

> 원칙: 다 쪼개서 단품으로 팔 수 있게 하고, 정산 기준을 명확히 하고, 패키지로 묶어 할인한다. 가격은 ~9,900원으로 끝낸다.

## 1. 정산 기준
| 단위 | 뜻 |
|---|---|
| **1장** | 옷 아이템 1개. 상의·하의·아우터·원피스·신발은 각각 1장. 같은 옷 다른 색상도 각각 1장 |
| **1컷** | 납품하는 이미지 1장 |
| **1편** | 납품하는 세로(9:16) 숏폼 영상 1개 |

- **주인공 1장 원칙:** 맡긴 옷이 주인공이고, 컨셉샷·영상의 나머지 착장은 AI가 무난한 기본 코디로 채운다(무료).
- **코디 추가:** 같은 브랜드의 다른 옷을 함께 입히려면 그 옷 1장당 코디 추가 요금을 받는다. 그 옷의 누끼컷은 포함하지 않는다(필요하면 단품 누끼로 추가).
- **수정:** 결과물마다 수정 1회 무료. 이후 추가 수정은 유료.

## 3. 패키지 (12월 한정 프로모션)
할인 전 가격 = 같은 구성을 단품 정상가로 주문할 때의 합계.

| 패키지 | 구성 | 단품 합계 | 패키지가 |
|---|---|---|---|
| 이미지 팩 | 주인공 1장 · 누끼 7컷 + 모델 컨셉샷 5컷 | 218,800원 | **129,900원** |
| 풀 패키지 (추천) | 이미지 팩 + 시즌 숏폼 1편 | 868,700원 | **399,900원** |
| 룩 패키지 | 2장(상·하의 등) · 각 누끼 7컷 + 함께 입은 컨셉샷 5컷 + 숏폼 1편 | 957,900원 | **499,900원** |

계산
- 이미지 팩: 9,900×7 + 29,900×5 = 69,300 + 149,500 = 218,800
- 풀 패키지: 218,800 + 649,900 = 868,700
- 룩 패키지: 9,900×14 + 29,900×5 + 19,900×1 + 649,900 = 138,600 + 149,500 + 19,900 + 649,900 = 957,900

## 4. 이전 안에서 바뀐 것
- 129,000 → 129,900 / 299,000 → 299,900 / 399,000 → 399,900 (~9,900 맞춤)
- 누끼 추가 10,000 → 9,900, 컨셉샷 추가 30,000 → 29,900
- 이미지 팩 할인 전 가격을 399,000(임의 정가)에서 단품 합계 218,800으로 변경 → 근거가 명확함
- 룩 패키지, 코디 추가, 추가 수정 요금 새로 추가
