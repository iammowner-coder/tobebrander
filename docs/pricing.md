# tobebrander 가격표 (초안 v4 · 2026-11-26)

> 원칙
> - **판매는 패키지로만 한다.** 단품은 팔지 않는다.
> - 구성 요소를 쪼개 본 것은 **상품 개념을 잡고, 할인 전 가격과 추가 옵션 단가의 근거**로 쓰기 위해서다.
> - 이미지는 옷 1장당 이미지 팩(누끼 7컷 + 모델 컨셉샷 5컷)이 기본이다.
> - 가격은 ~9,900원으로 끝낸다.

## 1. 정산 기준
| 단위 | 뜻 |
|---|---|
| **1장** | 옷 아이템 1개. 상의·하의·아우터·원피스·신발은 각각 1장. 같은 옷 다른 색상도 각각 1장 |
| **1컷** | 납품하는 이미지 1장 |
| **1편** | 납품하는 세로(9:16) 숏폼 영상 1개 |

- **이미지 팩 기본:** 옷 1장마다 누끼 7컷 + 모델 컨셉샷 5컷.
- **주인공 1장 원칙:** 맡긴 옷이 주인공이고, 컨셉샷·영상의 나머지 착장은 AI가 무난한 기본 코디로 채운다(무료).
- **수정:** 결과물마다 수정 1회 무료.

## 2. 구성 요소 (내부 기준 · 따로 팔지 않음)
| 요소 | 단위 | 기준가 | 쓰임 |
|---|---|---|---|
| 누끼컷 | 1컷 | 9,900원 | 할인 전 가격 계산, 추가 옵션 단가 |
| 모델 컨셉샷 | 1컷 | 29,900원 | 할인 전 가격 계산, 추가 옵션 단가 |
| 시즌 숏폼 영상 | 1편 | 649,900원 | 할인 전 가격 계산 |

## 3. 패키지 (판매 상품 · 12월 한정 프로모션가)
| 패키지 | 구성 | 할인 전 | 패키지가 |
|---|---|---|---|
| 이미지 팩 | 1장 · 누끼 7컷 + 모델 컨셉샷 5컷 | 218,800원 | **129,900원** |
| 풀 패키지 (추천) | 이미지 팩 + 시즌 숏폼 1편 | 868,700원 | **399,900원** |
| 룩 패키지 | 2장 · 누끼 14컷 + 함께 입은 컨셉샷 10컷 + 숏폼 1편 | 1,087,500원 | **499,900원** |

계산
- 이미지 팩: 9,900×7 + 29,900×5 = 218,800
- 풀 패키지: 218,800 + 649,900 = 868,700
- 룩 패키지: 9,900×14 + 29,900×10 + 649,900 = 1,087,500

## 4. 브랜드가 고르는 것: 몇 장? 몇 벌?
세부 옵션 대신 브랜드의 직관적인 고민 두 가지만 풀어 준다.

1. **장으로 할까, 벌로 할까?**
   - 장으로 (한 장씩): 맡긴 옷 1장이 주인공, 나머지는 기본 코디 → 이미지 팩 / 풀 패키지
   - 벌로 (한 룩으로): 상의·하의 2장을 한 벌로 맞춤 → 룩 패키지
2. **몇 장(몇 벌)이면 얼마?** → 패키지가 × 수량. 사이트 계산기가 받게 되는 컷·영상 수와 합계를 바로 보여 준다.

수량 할인은 아직 없다.
