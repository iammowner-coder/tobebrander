# tobebrander 가격표 (초안 v5 · 2026-11-26)

> 원칙
> - **판매는 패키지로만 한다.** 단품은 팔지 않는다.
> - 구성 요소를 쪼개 본 것은 **상품 개념을 잡고, 할인 전 가격과 추가 옵션 단가의 근거**로 쓰기 위해서다.
> - 이미지는 옷 1장당 이미지 팩(누끼 7컷 + 모델 컨셉샷 5컷)이 기본이다.
> - **주인공 옷 원칙:** 컨셉샷과 영상은 고른 옷 1장을 주인공으로 포커싱·연출한다. 함께 입힐 옷은 참고 이미지로 받아 무료로 스타일링한다(그 옷의 누끼·전용 컷은 없음).
> - 가격은 ~9,900원으로 끝낸다.

## 1. 정산 기준
| 단위 | 뜻 |
|---|---|
| **1장** | 옷 아이템 1개. 상의·하의·아우터·원피스·신발은 각각 1장. 같은 옷 다른 색상도 각각 1장 |
| **1컷** | 납품하는 이미지 1장 |
| **1편** | 납품하는 세로(9:16) 숏폼 영상 1개 |

- **이미지 팩 기본:** 옷 1장마다 누끼 7컷 + 모델 컨셉샷 5컷.
- **주인공 1장 원칙:** 맡긴 옷이 주인공이고, 컨셉샷·영상의 나머지 착장은 AI가 무난한 기본 코디로 채운다(무료).
- **수정:** 결과물마다 수정 1회 무료.

## 2. 구성 요소 (내부 기준 · 따로 팔지 않음)
| 요소 | 단위 | 기준가 | 쓰임 |
|---|---|---|---|
| 누끼컷 | 1컷 | 9,900원 | 할인 전 가격 계산, 추가 옵션 단가 |
| 모델 컨셉샷 | 1컷 | 29,900원 | 할인 전 가격 계산, 추가 옵션 단가 |
| 시즌 숏폼 영상 | 1편 | 649,900원 | 할인 전 가격 계산 |

## 3. 패키지 (판매 상품 · 12월 한정 프로모션가)
옷 1장마다 둘 중 하나를 고른다. 섞어서 주문할 수 있다.

| 패키지 | 구성 (옷 1장 기준) | 할인 전 | 패키지가 |
|---|---|---|---|
| 이미지 팩 | 누끼 7컷 + 모델 컨셉샷 5컷 | 218,800원 | **129,900원** |
| 풀 패키지 (추천) | 이미지 팩 + 그 옷이 주인공인 시즌 숏폼 1편 | 868,700원 | **399,900원** |
| 룩북 패키지 | **준비 중** — 시장 조사(룩북당 평균 소개 벌 수, 룩북 전용 숏폼 톤) 후 구성·가격 확정 | — | — |

계산
- 이미지 팩: 9,900×7 + 29,900×5 = 218,800
- 풀 패키지: 218,800 + 649,900 = 868,700

## 4. 브랜드 입장에서 고르는 법
- 옷마다 "이미지만(129,900원)" 또는 "이미지 + 영상(399,900원)".
- 합계 = 이미지 팩 수 × 129,900 + 풀 패키지 수 × 399,900. 사이트 계산기가 1장 더할 때마다 얼마가 붙는지와 받게 되는 컷·영상 수를 보여 준다.
- 상황 예시
  - 신제품 누끼 위주: 이미지 팩 N장 (누끼 가격에 모델 컷까지 받는다는 점을 장점으로)
  - 누끼부터 영상까지 빠르게: 풀 패키지
  - 룩북: 룩북 패키지(준비 중). 그 전까지는 이미지 팩 여러 장 + 대표 옷 풀 패키지 조합

### 사이트에 따로 표시하지 않는 내부 기준
| 항목 | 단위 | 가격 | 사이트 |
|---|---|---|---|
| 누끼컷 추가 | 1컷 | 9,900원 | 안내 문구 한 줄 |
| 모델 컨셉샷 추가 | 1컷 | 29,900원 | 안내 문구 한 줄 |
| 추가 수정 (이미지 / 영상) | 1컷 / 1회 | 9,900원 / 29,900원 | 표시 안 함 |

### 정할 것
- 함께 입힐 옷(참고 이미지) 상한: 1착장당 최대 몇 개까지 무료인지
