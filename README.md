# tobebrander

의류 브랜드를 위한 AI 릴스 대행 서비스 랜딩 페이지.

> 새로운 시즌, 신제품, 어떤 상황에서든 의류 브랜드는 콘텐츠가 필요하다.

## 구성
- `index.html` · `styles.css` · `main.js` — 빌드 없는 정적 페이지 (GitHub Pages 바로 배포 가능)
- `research/brandazine-분석.md` — 경쟁·참고 서비스 분석 (원본 수집본은 저장소에 올리지 않음)
- 디자인은 브랜더진의 레이아웃 문법(흰 배경·흑백 단계·가운데 큰 제목·회색 둥근 카드·큰 숫자)을 참고했고, 문구·이미지·코드는 새로 만들었다.

## 로컬에서 보기
```bash
python3 -m http.server 8000
```
→ http://localhost:8000

## 자주 고칠 값
`main.js` 맨 위 `CONFIG`에서 한 번에 바꾼다.
- `remainingSlots` — 잔여 신청 구좌 (지금 7)
- `oldTotal` / `newTotal` — 비용 비교 합계 (3,000,000 → 399,000)
- `stepCosts` — 기존 촬영 7단계별 비용 (지금은 임시값, 합 300만 원)
- `formEndpoint` — 신청 폼 접수 주소
