## 1. 한 줄 정의
"브랜드를 위한 크리에이터 마케팅 플랫폼". 사람(인플루언서) 네트워크로 콘텐츠를 만든다. **AI 제작 아님.**
운영사 (주)인에디트, 성수동. 브랜드 2,000+, 크리에이터 10,000+ 주장.

## 2. 상품 구조
| 상품 | 방식 | 핵심 문구 |
|---|---|---|

## 3. 가격 (월, VAT 별도)
LITE 19만~39만 · XS(1인 패션) 49만 · S(소규모) 69만 · M(중형, 추천) 99만 · L(대형) 139만
- 차등 기준 = 쇼룸 아이템 수(30/50/100/200)
- 연간 결제 30% 할인, 판매·유가 캠페인·2차 라이선스는 추가 수수료

- 홈 / 쇼룸 / 스토어 / 스튜디오 / 스튜디오 프로 / SOLARI

- 가격, FAQ, 크리에이터 갤러리·맞춤 추천, 크리에이터 혜택, 롱블랙 제휴 페이지
- 리드 수집: 소개서 받기(이메일+인스타) / 시작하기(브랜드명·카테고리·국가·연락처) / 미팅 예약

## 5. 홈 흐름 (설득 순서)
1. 헤드라인 + "기획 → 제작 → 성과 지표 → 2차 활용까지"
2. 숫자 증명 (브랜드 2,000+, 크리에이터 10,000+)
3. 상품 3개 카드 (쇼룸 / 스튜디오 / 스튜디오 프로)
4. 고객사 로고·팔로워·협업 수
5. FAQ 5개
6. 마지막 CTA "미팅 예약하기"

## 6. 고객이 말하는 가치 (후기에서)
- "6개월간 약 1,000개 콘텐츠", "매월 100건 이상", "마케터 3명 일을 1명이"
- "복잡한 크리에이터 연결 과정 간소화", "시즌별 트렌드에 빠르게 대응"
→ 고객이 사는 것은 **콘텐츠 양 + 속도 + 인력 절감**

## 7. tobebrander에 주는 시사점
**같은 문제를 풀고, 다른 방법을 쓴다.**
- 브랜더진도 "시즌·신제품마다 끊임없이 콘텐츠가 필요하다"를 팔고 있다 → 시장 수요는 검증됨.
- 그러나 여전히 **사람이 입고 찍는다**: 재고 발송, 대여, 분실·손상 변상, 크리에이터 섭외·일정, 가이드 미준수 반려가 생긴다.
- tobebrander는 **모델·스튜디오·스태프·대기 시간·핏 맞추기 자체를 없앤다.** 제품 사진만 받아 AI 릴스로 만든다.
- 브랜더진의 2차 라이선스(광고 소재 사용료 별도)도 약점: 우리는 처음부터 **브랜드 소유 소재**로 납품 가능.

| | 브랜더진 | tobebrander |
|---|---|---|
| 제작 주체 | 크리에이터(사람) | AI 모델·AI 연출 |
| 필요한 것 | 실물 재고 발송 | 제품 사진 |
| 리드타임 | 섭외·대여·게시 일정 | (정해야 함) |
| 광고 소재 권리 | 2차 라이선스 별도 구매 | (정해야 함 — 기본 포함 검토) |
| 강점 | 실제 인플루언서 계정 노출 | 비용·속도·무제한 변형 |
| 약점 | 일정·재고·관리 비용 | 실제 계정 노출 없음, AI 신뢰도 |

### 벤치마킹할 것
- 브랜드 규모별 요금제(아이템 수 기준) → 우리는 "월 릴스 편수" 기준이 자연스러움
- 소개서 받기(이메일 하나) 같은 가벼운 리드 수집
- 셀프 / 대행 두 갈래 상품
- 블로그로 사용법·비교 글(대행사 vs 직접, UGC 광고 활용) 쌓기
